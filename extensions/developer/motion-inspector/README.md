# Motion Inspector

Install the supplied `.waffle-extension` package from **Tools → Extensions → Install from package** and approve the animation diagnostics, command, and panel grants, then select **Enable**. From a source checkout, use **Load unpacked** with this folder after turning on Developer Mode.

Open **Motion Inspector** in the command palette or Window → Panels. Use the sample form to repeat a track at a chosen time and inspect its retargeted value. Closing the panel ends polling.
