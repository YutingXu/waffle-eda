## Notebook typefaces

These static TrueType subsets use the SIL Open Font License 1.1. Each modified face has a Waffle Note family name. `python3 scripts/notebook-fonts.py --refresh` takes the original Google Fonts binaries from commit `06bfe0d62a98375cb09c942fa18e68bd32cff057`, instantiates the selected weights, subsets available Latin and engineering symbols, and stores the resulting licensed data in `app/vendor/notebook-fonts/faces.json`. Asset preparation wraps this data for offline canvas and PDF use.

## Not redistributed
- **Rust engine (`engine/`).** Has no third-party crate dependencies.
- **Python.** The MCP server and the Linux host use the Python standard library. PyGObject, GTK and WebKitGTK are system libraries installed by the user's distribution and are not bundled.
- **System webviews and JavaScriptCore.** WKWebView, WebKitGTK and JavaScriptCore are provided by the operating system.
