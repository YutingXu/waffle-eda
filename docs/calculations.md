# Calculations in the engineering notebook

**Calculation design.** A calculation on a sheet and an Answer in the Waffle palette use one expression language, unit system, resolver, evaluator and formatter. For a 10 kΩ resistor and a 1 nF capacitor, `f_c = 1/(2π·R5·C3)` gives 15.915494309… kHz and displays **15.92 kHz**. Changing C3 to 10 nF updates the display to **1.592 kHz**. Applying a value to a part is an explicit edit.

The [engineering helper reference](calculation-helpers.md) lists the available conversions, signatures and units.

## Language and dimensions

The parser consumes original-case Unicode text and records half-open UTF-16 source spans. Accept decimal and scientific literals, parentheses, unary signs, `+`, `−`/`-`, multiplication `*`/`·`/`×`, `/`, right-associative powers `^`/`**`, parallel `||`/`∥`, function calls and a final `in unit` conversion. A named block may start with `name =`. In an assertion, `=` tests equality and `= target ± tolerance` tests a closed band. Keep the source and diagnostic span through parsing, binding and evaluation. Entries such as `/math` can pass their argument to the sheet editor as entered.

Read grouped expressions and calls first, then powers, unary signs, multiplication/division, parallel, addition/subtraction and comparisons. Multiplication and division associate left to right. Thus `-2^2` is −4. A numeric coefficient may precede `π` or `pi`. A number may precede its unit directly or with a space. A repeated operator, unknown identifier, incompatible dimensions, ambiguous reference, division by zero or invalid logarithm produces a located diagnostic. Expression evaluation uses only the operations in this language.

A quantity carries a magnitude in coherent SI, the seven exponents for metre, kilogram, second, ampere, kelvin, mole and candela, plus semantic tags where needed. Add, subtract and compare compatible quantities. Multiply and divide add or subtract exponent vectors. Powers and roots transform dimension exponents. A dimensioned base accepts a constant exponent when the real-valued result has representable dimensions. A variable exponent needs a dimensionless base. Trigonometric functions accept radians and explicit degrees (`deg` or `°`). Logarithms require positive dimensionless ratios. Absolute Celsius readings convert with their offset. Their difference is a temperature interval, which can be added to an absolute reading. Convert an affine reading to kelvin before multiplication. Preserve distinctions such as angle and absolute power level alongside dimensions. [BIPM SI Brochure](https://www.bipm.org/en/si-brochure-9)

Recognise SI prefixes from quecto to quetta and preserve case. A bare prefix only scales a dimensionless number. Directly after a number `m` is milli, `M` or `meg` is mega, and `u`, `µ` or `μ` is micro. Write `metre`, a prefixed physical unit such as `mm`, or a length unit such as `mil` or `in` for length. A trailing `in` after a number means inches. When a conversion target follows, `in` introduces the target. `Ω` and `ohm` are interchangeable. One mil is 0.0254 mm. Explicit preferred-value requests use `3.3k in E24` or `nearest E96 3.31k`. A bare series after a value is invalid. `3.3E24` is a single scientific literal. [SI prefixes](https://www.bipm.org/en/measurement-units/si-prefixes/)

Typed bindings supply units. A resistor's `R5.Value = "10k"` is 10 kΩ and a capacitor's `C3.Value = "10n"` is 10 nF. An explicit compatible unit takes precedence. Unbound literals preserve their own dimensions through every operator and preferred-value query. For example, `10k * 10n` is dimensionless and `10kΩ ∥ 4.7k` produces a dimensional diagnostic, independently of the current selection.

Apricot Preview uses the declared unit of a numeric field for a bare entry. A power field in watts reads `250m` as **250 mW**. The same rule applies to the right side of `power < 250m` and to a calculation assertion comparing a bound power field with `250m`. An explicit compatible unit wins, so `0.25 W` and `250 mW` have the same value. A current such as `250 mA` gives a diagnostic at the incompatible operand. A temperature-coefficient field can declare `ppm/K`. Quick Maths outside a field continues to read `250m` as the dimensionless number 0.25.

`ea` and `pcs` denote a count. BOM Quantity has this unit. `count(LED)` runs the design query against the calculation’s project revision and returns its complete number of matches in `ea`. An unavailable measurement, denied scope or unfinished query produces a diagnostic. The sheet, Quick Maths and numeric fields share the same quantity and formatter. `2 ea + 3 pcs` gives **5 ea**, `3 ea * 20 mA` gives **60 mA**, and `6 ea / 3 ea` gives **2**. A plain multiplier or divisor scales a count. For example, `2 * 3 ea` gives **6 ea**, `6 ea / 2` gives **3 ea**, and `6 / 3 ea` gives the ratio **2**. Adding a bare number, percentage or current to a count produces a dimensional diagnostic at the incompatible operand. In `assert count(track where width < 0.15 mm) = 0 ea`, the zero counts tracks. Comparing that count with an explicit ratio such as `2 V / 2 V` produces a dimensional diagnostic. Project and library field declarations supply the same hints to the query compiler. [Query grammar and values](query-language.md#grammar-and-values)

Parse each complete decimal significand and exponent directly to its correctly rounded IEEE 754 binary64 value with round-to-nearest, ties-to-even. Arithmetic, unit factors, derivatives and graph values use binary64 throughout. Use adjacent representable values for outward rounding of worst-case bounds. Equality and closed boundaries treat two coherent values as equal when `abs(a-b) <= 1e-12 * max(abs(a),abs(b))`; equality with zero thus requires zero. Strict comparisons exclude equality under that rule. Comparisons, snapping and dependent expressions use unformatted magnitudes. Every consumer displays and copies all digits of a known exact safe integer count, such as **12345 ea**. Other numeric readouts use four significant figures and suppress insignificant trailing zeros, including fractional counts and decibels. The conventional `20·log10(2)` amplitude-ratio expression displays **6.021 dB**; `10·log10(ratio)` is its power counterpart. A standalone logarithm yields a dimensionless number.

## Live inputs and authored records

Resolve `R5`, `R5.Value`, part parameters, `net VDD.voltage`, sheet/project properties and named calculations through the same design-field service proposed for rich text. A typed component's bare designator selects its Value. Parameter lookup respects placement overrides and library inheritance. Net voltage needs an authored, unit-bearing property or an identified source with provenance. A matching net name alone supplies no voltage. Use `net 48V.voltage` for a numeric-leading rail. Quote names containing spaces or punctuation, as in `net "Battery +/A::sense.1".voltage`. Single and double quotes are accepted. A backslash escapes the chosen delimiter or another backslash. The resolver binds the selected signal ID and field. A sheet-qualified name resolves across sheets. An unqualified ambiguous match offers candidates with sheet and instance names. Resolution stays incomplete until a unique target is selected.

A reference keeps its occurrence ID, project document ID, object or signal ID, stable field key and, when applicable, hierarchy instance path. Use an addressable authored net/signal identity. A connectivity-only net may be bound through a stable terminal anchor in a specific instance when it resolves uniquely to the chosen property. A split, merge or ambiguous channel that breaks the binding requests repair. Designators and display aliases may change without breaking identity. Deletion shows a broken reference and offers deliberate rebinding. Undo restoring the same ID repairs the original reference. A different part subsequently named R5 never claims it automatically. A bare name typed into a separate quick query is resolved anew.

Proposed for the 2.0 sheet schema, each display block is a non-electrical `calculation` record with a stable ID, position in integer nanometres, language version, expression source, optional result name/display unit and stable token bindings. Assertion clauses have individual stable IDs, even when a block has several clauses. Source edits remap surviving token occurrences by identity and rebind edited tokens. Collaborative edits, copy and paste remap internal IDs using the existing object machinery. Cross-project paste marks external references that need rebinding. The record carries authored tolerance and function-version choices. Numeric answers, parsed trees, diagnostics, graph edges, thumbnails and check outcomes are derived. Their caches belong to the ignored workspace cache. [Canonical records](format-2.md#canonical-records-and-dimensions)

## Tolerances and assertions

`10 kΩ ± 1%` has a 100 Ω half-width. `10 kΩ ± 25 Ω` has a 25 Ω half-width. A dimensional absolute tolerance must match the central value. Reject negative widths. Carry a stable uncertainty-source identity through every reuse of an input.

- **Worst case** returns a conservative enclosing interval with outward rounding. Use monotone extrema where known, and bounded interval arithmetic for a general expression. Preserve repeated variables, including exact cancellations such as `R5−R5`. Flag conservative overestimates for more complex shared inputs. An interval crossing a denominator zero has an undefined/unbounded result.
- **RSS** estimates a combined tolerance from local sensitivities. With independent bounded inputs the engineering half-width is `sqrt(sum((∂f/∂xi · hi)²))`. Group occurrences of one source before combining sensitivities. Label the independence and linearisation assumptions. If a function is discontinuous, a derivative is unavailable or the approximation is unsuitable over the given range, report RSS unavailable with its reason. Keep a conservative worst-case result where defined.

When a bound part has no tolerance, treat it as exact for both calculations and label the result and every dependent assertion **tolerance unknown: R5, C3**, listing the affected parts once. An optional project rule-book setting provides a default tolerance by component type. Use it when an explicit tolerance is absent and label the input and result **default** with the value and source. An explicit zero tolerance is known and takes precedence. Numeric literals are exact inputs. Reserve a versioned extension point on the result type for future uncertainty methods.

`assert f_c > 10 kHz` compares like dimensions. `assert Vout = 3.3 V ± 2%` accepts 3.234 V through 3.366 V inclusive. The default guarantee uses the whole worst-case input interval. A contained interval passes. An interval entirely outside fails. Partial overlap yields a finding labelled “May violate” with the measured and required ranges. An undefined expression or missing dependency yields an incomplete check, with a direct link to its source span. An author who wants a nominal-only comparison writes `nominal(Vout)` explicitly. A disabled rule displays its disabled state. The rendered block uses a checkmark and “Pass”, a cross and “Fail”, or the corresponding text and icon for a possible violation, pending or unavailable result.

For every authored assertion, create one rule of proposed type `ercCalculationAssertion` in the existing project rule book. Its stable rule ID, `where: "schematic"`, sheet scope, severity, enabled flag and origin `{kind:"calculation",sheet:<sheetId>,object:<blockId>,assertion:<clauseId>}` point to the single authored predicate in the block. Rules and Constraints lists these rules in a **Calculations** group, subgrouped by sheet. Each row links to its source clause. Editing severity or enabling a rule edits the ordinary rule book. Editing the predicate from either surface edits its one source. Create/delete/copy/move the clause and corresponding rule in one transaction and Undo step, with fresh IDs for copies. A frame-to-sheet move keeps the clause and rule IDs and updates their sheet references. [Project rule model](../app/checks/project-rules.js) · [Unified rules and checks](design/unified-rules-and-checks.md)

Register one `schematic.calculationAssertion` check in `AtriumChecks` and one corresponding ERC check type. The scheduled ERC pass consumes the evaluation result for its design revision and publishes the existing violation shape with rule ID, severity, document and block IDs, source span, actual and required quantities. Key findings by stable rule, block, clause and instance so numeric drift or moving a note cannot duplicate a finding. A changed predicate invalidates a waiver's meaning signature. ERC, Problems, Insights and MCP consume that published finding, including existing scoped severity, mute/waiver and release settings. An evaluator supplies a value or diagnostic. The central checker decides the finding. A plain calculation participates in the Notes group and never contributes an electrical net, pin or ERC rule. [Check registry and scheduler](../app/checks/checks.js) · [ERC](../app/checks/erc.js)

## Evaluation and display

Load the parser and worker on the first calculation, quick-maths request or widget that uses them. Opening a design without calculations performs no calculation parsing or evaluation. Build a versioned graph of authored input fields, calculations and assertions with forward and reverse edges. Subscribe to committed design changes through the existing edit pipeline/undo journal. Cache by expression/binding revision, dependency revisions, instance and function package version. After editing one capacitor, mark only its dependent subgraph dirty. Rebinding a token replaces its edges. Undo, redo, remote edits, library updates, net-property changes and deleted targets go through the same invalidation path.

Evaluate a dependency closure topologically in a worker. Detect strongly connected components, including self-loops, and show a cycle path with links to its blocks. Propagate the blocked state to dependants while independent branches continue. Tolerances share the parsed graph. Prioritise the visible block and the current palette query. Coalesce requests, bound work and cancel obsolete revisions. Return serialisable quantities, dimensional metadata, display strings, source spans and diagnostics. Accept a response only while its source and design revision still match. A warm query reads cached projected fields. A cold cross-sheet reference requests just the authorising document/dependencies and shows “Loading input” while pending. Explicit Compile, release or PDF requests the full closure for its snapshot and reports incomplete inputs.

The notebook’s glyph and line layout displays the equation, result and assertion status. Input chips support hover, keyboard focus and tap/hold to show the source, resolved value, unit, tolerance and sheet. Go to source opens the referenced object. Tooltips avoid covering their anchor. Support light/dark tokens, Reduce Motion, 44 pt touch targets, screen-reader text and pen operation. Place notebook geometry outside the electrical hit/connection paths.

MCP extends the existing read-only `calculate` operation with an expression form and a stable block-ID query, retaining named calculator inputs. Return the same quantities, units, ranges, status, input IDs and revision used in the UI. Any write follows the existing explicit proposal/apply flow. Compare and History independently evaluate each side against that side's bindings and function versions. Under **Notes**, distinguish a formula edit from a result changed by an input. PDF evaluates one frozen project revision and uses selectable vector maths with readable values, units and assertion states. Altium/KiCad export the current value as static text or the rendered equation as an image, and the fidelity report identifies the source block, conversion and lost live binding. ## Engineering functions

The first catalogue includes arithmetic, `abs`, `min`, `max`, `sqrt`, `exp`, logarithms, trigonometry, parallel resistance, engineering unit conversions, corner frequency, E-series, resistor colours and wire gauge. Give every function a fixed dimensional signature, arity, domain, tolerance behaviour and return type. Typed records such as a band decoding expose named result fields. Text output is copyable. Only a compatible scalar value is applicable to a part.

| Helper | Behaviour |
|---|---|
| Preferred values | Support E3, E6, E12, E24, E48, E96 and E192. Reuse the pure values and `AtriumCalc.nearest` from the Calculators panel. Use minimum absolute log ratio, show signed error and select the lower nominal on an exact tie. Snapping is explicit and occurs in the target physical unit before formatting. [Calculator implementation](../app/analysis/calculators.js) · [IEC 60063](https://webstore.iec.ch/en/publication/22011) |
| Resistor colours | Decode three, four, five or six bands with digit count, multiplier, tolerance and optional TCR in ppm/K. Encode a resistance and specified tolerance to the requested band count, with TCR for six bands. Report an unrepresentable value or ambiguous order rather than silently rounding. Provide both names and coloured bands. [IEC marking code](https://webstore.iec.ch/en/publication/65655) |
| AWG | Convert a solid round conductor's gauge to bare diameter and area and reverse to the nearest gauge with error. With 0, 00, 000 and 0000 mapped to n = 0, −1, −2 and −3, diameter is `0.127 mm · 92^((36−n)/39)`. This helper returns wire geometry. [US Bureau of Standards wire tables](https://nvlpubs.nist.gov/nistpubs/Legacy/hb/nbshandbook100.pdf) |
| Decibels and voltage | Power ratios use `10 log10(P/P₀)`. Amplitude ratios use `20 log10(V/V₀)` with the amplitude convention shown. Absolute dBm requires power relative to 1 mW. Conversion from dBm to RMS volts requires an explicit positive resistive load, using `Vrms = sqrt(P·R)`. For peak/peak-to-peak, require a waveform or declared crest factor. dBV uses 1 V RMS as its reference. A bare “dB in volts” asks for the missing reference. |
| Frequency, period, wavelength | `period(f) = 1/f` and `frequency(T) = 1/T` require positive arguments. `wavelength(f,v) = v/f` needs a positive propagation speed. `c` explicitly selects the speed of light in vacuum, 299792458 m/s. A board calculation may bind the phase velocity of an identified stackup/profile. Show the chosen medium or velocity. |

Extensions declare `contributes.mathFunctions` with package-qualified ID, version, typed arguments, return dimensions, domain and a pure expression body. Validate the AST at install/enable and execute it with immutable argument values in a computation-only worker under the existing extension sandbox. Bodies may compose allowed built-ins and declared pure dependencies. Block unevaluated recursive cycles and enforce depth, instruction, memory, response-size and wall-time budgets. Omit side-effectful host RPCs, DOM, network, files, storage, callbacks, clocks, randomness and dynamic code generation from the function language even when the extension has permissions for its other features. Terminate or cancel overruns, return a located error and retain the host's responsiveness. A missing, disabled or different package version produces an unavailable result until the user selects a compatible installed version. A cached historical display is labelled with its version. [Extension sandbox](../app/workers/extension-host-worker.js) · [Extension API](extension-api.md)

A declarative calculator Form in the existing palette can take `Vin = 5 V`, `Rtop = 1 kΩ`, `Rbottom = 2 kΩ` and call the same pure `divider(vin,rtop,rbottom) = vin·rbottom/(rtop+rbottom)` function as a widget or sheet. It displays **3.333 V** from 3.333333… V. The extension returns a view and a typed answer. Only an explicitly selected host action can place or apply it. Validate returned dimensions and finite values before presenting a result.

## The palette Answer contract

The lazy host bridge is `AtriumCalculations` in `app/calculations.js`. Integrate it as one read-only local Answer provider in the existing palette/search engine. Keep project objects, library components, commands, settings, help and extension providers in their established index. Pass the raw input before the search index lowercases or normalises Greek letters and SI prefixes. `>`, `@` and `:` retain their command, jump and coordinate meanings. [Palette](../app/editor/palette.js) · [Search index](../app/editor/search-index.js)

- `acceptsPaletteText(text, context?) -> boolean` uses a bounded synchronous intent check from the shared lexer. It recognises a plausible expression or a partially typed calculation without evaluating it or scanning the project. The palette loads the small shared recogniser on open and loads the worker on demand. Reserve the Answer slot above other results only for accepted input. A normal word search or an unavailable calculation capability uses the ordinary palette layout.
- `answer({queryId,text,projectRevision,documentId,instanceId?,selection?},{signal}) -> Promise<null | Answer>`. Context and selection carry IDs. A ready answer carries the request ID and revision, an opaque result key, original source, formatted display and copy text, physical dimension, bound field IDs, and its eligible host action names. A diagnostic carries the matching ID and revision, a short message and half-open UTF-16 span. A non-maths query yields null. The worker completes the reserved slot as local search results already appear. Cancelling on each keystroke, editor switch or dependency revision prevents stale output. A slow function cannot reorder results already shown.
- Enter copies the displayed answer. Option/Alt+Enter inserts a bound calculation block at the captured pointer/tap anchor in a writable schematic. Shift+Enter applies the result to the Value field of exactly one selected, editable, compatible part. Offer a named E-series snap when requested and show its resulting value. Explicit buttons in the actions panel provide all three operations for touch and pen.
- The host handles copying. `AtriumCalculations.applyPaletteAnswer(answer, action, context)` handles explicit insert/apply through the sheet action adapter. Recheck the revision, result key, selection, stable target, compatible dimensions, locks, release state and write permissions immediately before commit. If anything changed, refresh and show the revised target/value. Commit one undoable edit with a single redo. Querying, copying, opening the actions panel and cancelling a stale result perform zero design edits. The same action validation applies to a calculator Form.

| `1/(2π·10k·10n)`, `1/(2*pi*10k*10n)` | Both are dimensionless and display **1.592 k**. Binding R5 = 10 kΩ and C3 = 1 nF in the same expression gives **15.92 kHz**. |
