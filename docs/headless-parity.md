# Headless parity

Generated by `scripts/headless-inventory.py` from the menus (`app/index.html` buttons and slots, `menuItem` additions), keymap commands (`app/editor/keymap.js`, `registerCommand`), lazy registrations, `registerAction` handlers and the editor's `act` switch. Regenerate these files with the script. `tests/automation/headless-parity.py` fails when an action has no mapping.

Headless paths run in the MCP server (`python3 mcp/server.py --project X.waffle`) and the CLI (`--cli run_command --args '{"command": "align", "args": {...}}'`). Editing commands finish as an `.waffle-ai` proposal, or write in place only with `--allow-write` and `"mode": "write"`. `"mode": "plan"` reports the change without writing anything. Generated files stay under `<project>-outputs/`.
