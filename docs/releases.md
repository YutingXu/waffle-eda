# Waffle EDA release codenames

Waffle EDA names each major release after a flavour. Previews and patch builds keep the flavour of their release. About and the installer notes show the release name and version. Package filenames and update checks use the numeric version.

| Version | Flavour | Release highlights |
| --- | --- | --- |
| 0.7.0 | Apricot Preview | Native format 2.0, source EDA importers, active-document saves, recovery, project hierarchy and infinite sheets. Notebook features were available behind a preference. |
| 0.8.0 | Butter | Query language, project history, macros, project windows, drag and drop, motion settings, PDF reading, tables, slides, Ask AI and ODB++ export. |

Apricot Preview introduced native format 2.0 and its compatibility policy. Designs from pre-release 1.x builds can be re-imported from their original Altium, KiCad or other source EDA project. [Format compatibility](format-versioning.md) · [Upgrading](upgrading.md)

[Butter release notes](release-notes.md) · [Downloads](../../../releases)

The planned names after Butter are Caramel, Dark Chocolate, Espresso, Fig, Ginger and Hazelnut.
